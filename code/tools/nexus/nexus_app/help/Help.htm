Nexus - Asset Preview Tool

Help

Overview

Nexus is a tool for previewing XSI and A3D art assets. Skinned object animation is supported in addition to static scenes.

Controls

The camera is controlled using the same key and mouse operations as Maya.

'Space' stops/starts any animation.

'R' Sets the current animation time to the time of the first frame.

'C' Centres the camera.

'A' Frames the scene within the camera's view.

'Right cursor' Increase the current animation time by a small amount.

'Left cursor' Decrease the current animation time by a small amount.
